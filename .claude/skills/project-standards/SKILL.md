# Project Standards Skill

## Purpose
Keep Monster2.0 consistent, maintainable, and evaluation-ready.

## Project Rules
- Build a Monster-inspired job portal with original branding, copy, colors, and assets.
- Do not copy Monster.com logos, images, exact text, proprietary CSS, or trademarked branding.
- Preserve the stack: React + Vite frontend, Node.js + Express backend, MongoDB + Mongoose.
- Use only free-tier services and document setup clearly.
- Keep changes small and milestone-based.

## Quality Bar
- Keep code modular and readable.
- Use environment variables for secrets and URLs.
- Keep auth and role checks server-side.
- Add frontend loading, empty, error, and success states.
- Keep UI responsive for desktop and mobile.
- Update README when setup, env, scripts, routes, or deployment steps change.

## Before Editing
- Inspect current file structure.
- Check existing naming conventions.
- Avoid unrelated refactors.
- Do not remove working features while adding new ones.

## Verification
- Run relevant frontend/backend scripts.
- Test key flows manually in browser.
- Confirm API behavior with Swagger, browser, or HTTP client.
